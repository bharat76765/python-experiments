# Python Experiments Repository

## Overview

This repository contains a collection of Python scripts and Jupyter notebooks that I wrote while getting started with Python. These projects and experiments helped me learn and apply various programming concepts in Python.

## Repository Structure

- **SPACE_to_EPIC**: A project related to space and EPIC data.
- **quiz game**: A simple quiz game implementation.
- **TEMPERATURE AND LENGTH CONVERTER**: A utility to convert temperature and length units.
- **guess the word game**: A game where the player has to guess a word.
- **luck_wallah**: A project related to generating random luck-based outcomes.
- **movie_reccomendation_system.ipynb**: A Jupyter notebook implementing a movie recommendation system using content-based filtering.
- **Content Based**: Additional resources or code related to content-based recommendation.
- **rock_paper_scizer**: A classic Rock-Paper-Scissors game.
- **tic_tac_toe**: Implementation of the Tic-Tac-Toe game.

## Description of Projects

1. **SPACE_to_EPIC**:
   - Description: A project involving space data and EPIC (Earth Polychromatic Imaging Camera) data processing or visualization.

2. **quiz game**:
   - Description: A simple interactive quiz game where users answer questions and receive scores.

3. **TEMPERATURE AND LENGTH CONVERTER**:
   - Description: A utility tool for converting between different temperature and length units.

4. **guess the word game**:
   - Description: A fun game where players try to guess a hidden word based on provided clues.

5. **luck_wallah**:
   - Description: A project that generates random luck-based outcomes, possibly a game or a random generator.

6. **movie_reccomendation_system.ipynb**:
   - Description: A Jupyter notebook that implements a movie recommendation system using content-based filtering techniques.

7. **Content Based**:
   - Description: Additional content-based recommendation code or resources, potentially related to the movie recommendation system.

8. **rock_paper_scizer**:
   - Description: The classic Rock-Paper-Scissors game implemented in Python.

9. **tic_tac_toe**:
   - Description: A simple implementation of the Tic-Tac-Toe game.
